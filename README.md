# 🎬 Netflix Content Analysis

## Description

This project analyzes Netflix content using Power BI.

The dashboard provides insights into movies, TV shows, genres, countries, ratings, and release trends.

## Project Objective

To analyze Netflix data and build an interactive dashboard that provides meaningful business insights.

## Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel
